# Known limitations of the reproduction

## Steps done outside this repository

- **Fig. 3B** is drawn on its own (`scripts/figures/fig3b.py`) and placed into Fig. 3 by hand.
- **Fig. 5** labels are set in a vector editor on top of the PDF that `scripts/figures/fig5.py` writes.
- **The parcellation figure of the supplement** (`fig:parcellations`, Cammoun parcellations at the three
  scales) is not generated by this repository.
- The manuscript itself is not part of the repository. `scripts/paper/sync.py` copies the generated tables,
  number macros and figures into a manuscript folder.

## Numerical reproducibility

- Results are bit-reproducible on one machine with BLAS pinned to one thread (the default). At 68 regions the
  closed-form Gramian kernel is nearly singular for some subjects (numpy warns about division by zero there),
  and multithreaded BLAS changes some set-level metrics at about $10^{-6}$ relative, enough to move a
  percentile by one rank. 114 and 219 regions are unaffected.
- The release reference was computed on macOS (arm64, numpy with Apple Accelerate). Other BLAS libraries (e.g.
  OpenBLAS on Linux) may differ in the same last digits. The synthetic fingerprints in
  `tests/golden/synthetic.json` are compared at a relative tolerance of $10^{-6}$ for this reason.
- The null-network ensemble (`null_models/01_run_nulls`) of the release run was computed once and reused (with
  per-file checksum verification) rather than recomputed; a sample of its per-subject chunks was recomputed with
  the released code and matched byte for byte. `paper/validation_report.md` and `paper/provenance.json` of the
  release run record this.

## "Legacy" rows of the target-state tables

The supplement reports, next to the corrected targets, the targets of the first version of the study: an
occipital mask that selected regions by substring (so it included precuneus) and a principal gradient
projected from fsLR to fsaverage5 without the registration between the spheres. `target_states/01_build_targets`
rebuilds both exactly (`hoc.analysis.target_states.legacy_targets`, `margulies_parcel(..., registered=False)`).
