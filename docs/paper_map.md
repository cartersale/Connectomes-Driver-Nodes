`runs/paper/paper/`. Paths in the *Reads* column are relative to the run directory `runs/paper/`; the
pipeline step that writes each one is listed in [pipeline.md](pipeline.md).

`scripts/paper/sections/` and writes `paper/tables/<id>.tex` (and `<id>_long.tex` for tables the supplement
sets as longtables); the supplement inputs them with `\stab{<id>}` / `\ltab{<id>}`. Shared formatting is in
`scripts/paper/common.py`. Each table's computation is described in `paper/tables/notes/<id>.txt`.

## Numbers in the text

`scripts/paper/key_numbers.py` (pipeline step `paper/numbers`) recomputes every number quoted in the main text
and supplement with the modules in `scripts/paper/registry/`:

| Part of the paper | Registry module |
| --- | --- |
| `subsec:energy_floor`, first part of `subsec:hub_concentration`, Fig. 1 and Fig. 2 captions | `main_energy_hubs.py` |
| end of `subsec:hub_concentration`, `subsec:leading_mode`, Fig. 3 caption | `main_leading_mode.py` |
| `subsec:core_divisions`, Fig. 4 caption | `main_core_divisions.py` |
| `subsec:nulls_results`, Fig. 5 caption | `main_nulls.py` |
| Methods | `methods.py` |
| Supporting Information (prose and captions) | `supplement.py` |

Each number's entry in `paper/numbers.csv` gives its source file and selection, the manuscript labels where it
appears, and what it refers to (scale, $k$, $c$, criterion, comparison, statistic).
